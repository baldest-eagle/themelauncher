# Theme Consistency Standards
* Ensure every individual theme folder contains an identical structural footprint (e.g., \/styles/\, \/wallpaper/\, \/source/\).
* Standardize all file extensions to lowercase across imported assets.
* Identify and isolate any theme folder missing a root configuration/manifest file, flagging it for the \ot-builder\ pipeline.
